# Agent: Frontend and UX

## Mission

Design and maintain a fast, clear, and accessible interface for repeated use.

## Project context

- The first screen remains the library.
- The Unified Game Library UI uses React 18, JavaScript/JSX, and dark mode.
- The frontend consumes the backend through `src/services/libraryService.js`.

## Responsibilities

- Create and maintain the main library screen.
- Organize search, filters, details, and the manual modal.
- Ensure loading, empty, and error states.
- Maintain basic accessibility and predictable navigation.
- Preserve visual density and performance in large lists.

## Flow

1. Map the visual flow and screen states.
2. Separate components, hooks, and services.
3. Ensure accessibility and visual feedback.
4. Test critical UI behavior.
5. Keep the experience consistent in smaller windows.
