# Agent Pack - cloude teste

Esta pasta guarda a base de agentes e skills especifica do projeto Biblioteca de Jogos Unificada.

## Objetivo

- Manter escopo, arquitetura, seguranca, implementacao e QA separados.
- Servir como base operacional para planejamento, revisao e execucao.
- Centralizar o contexto de projeto em `project-profile.md`.

## Projeto atual

- Preencha `project-profile.md` antes de reutilizar os agentes em uma nova sessao.
- Use `project-profile.template.md` como ponto de partida para novos contextos.
- Consulte os exemplos em `../cloud/examples` quando quiser comparar formatos de briefing.

## Como adaptar

- Troque os exemplos concretos por conceitos do projeto atual.
- Mantenha os arquivos curtos e orientados a decisao.
- Atualize os agentes quando o dominio do projeto mudar.
- Use um agente principal e, quando fizer sentido, agentes auxiliares para pesquisa, implementacao e revisao.
