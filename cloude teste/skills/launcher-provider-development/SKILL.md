# Launcher Provider Development

## Use when

- A provider must expose a launch action.
- The app needs URI, launcher or local executable behavior.
- Launch safety and user feedback matter.

## Checklist

- Define the launch contract.
- Keep the action explicit and structured.
- Validate safe local execution rules.
- Preserve fallback behavior and user feedback.
